# Security

Маяк хранит VPN-ключи локально.

## Сейчас

- Android: ключи шифруются через Android Keystore.
- Windows: файл профилей защищается DPAPI текущего пользователя, запись атомарная (temp + rename).
- Импортируется только VLESS Reality ключ, произвольный sing-box JSON не принимается.
- Desktop запускает bundled/local sing-box и Xray, PATH для поиска ядер не используется.
- Установщик собирается через `jpackage`, подписывать можно отдельно.
- `ensure-sing-box.ps1` проверяет SHA-256 скачиваемого бинарника.
- Релизы собираются в GitHub Actions.
- В репозитории не должно быть реальных ключей, подписок, доменов или IP.
- Загрузка подписок проверяет TLS-сертификаты. Переход с HTTPS на HTTP и перенаправления на другие схемы запрещены; размер ответа ограничен 2 МБ.
- Xray принимает SOCKS только на loopback. Конфиг удаляется при остановке; сохранённый PID используется только после проверки пути бинарника и аргументов процесса.
- На Linux и macOS каталог с профилями закрыт правами 0700.
- `ensure-xray.ps1` скачивает фиксированный официальный релиз и проверяет SHA-256.

## Ограничения

- Windows поддерживает Proxy и TUN. Для TUN нужны права администратора.
- WARP-регистрация создаёт отдельные Cloudflare WireGuard credentials и хранит их только локально через DPAPI.
- Android APK пока debug-signed. Для внешней раздачи нужен release signing.

## Если нашёл проблему

Пиши владельцу репозитория напрямую. Не публикуй рабочие ключи, логи с токенами и реальные VPS-адреса в issue.
